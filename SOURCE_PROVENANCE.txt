Rebuild with Rust, the x86_64-pc-windows-gnu target and a MinGW x64 linker:
  cargo build --release -p kh1-hook --target x86_64-pc-windows-gnu --locked
The resulting dinput8.dll is installed as kh1-dual-wield.dll through Panacea.
Do not put it in the shared game folder as a dinput8 proxy.

Local checks used:
  cargo test -p kh1-hook -p character-core -p combat-core -p kh2-rig -p kh1-data -p kh2-anim --locked
239 tests passed, including 10 new policy/controller checks. The full local
transcript and PE header/import/export report are included under validation.
Real-data optional checks need the player's own install. No in-game result
or actual Windows runtime execution is claimed by this package.
